# 预期效果、论文价值与业界落地

这个项目希望达成的效果是：**在模型训练之前发现可静态检查的数据问题，让问题可定位、
检查可复现、结果可归档。** 它是数据质量工程工具，当前没有新训练算法或已发表论文。

## 预期效果与当前证据

| 目标 | 已有证据 | 还需要验证什么 |
| --- | --- | --- |
| 提前发现常见格式与图片问题 | 16 类故障、128 个合成样例均触发目标规则；32 个正常对照无告警 | 独立标注的真实数据上的漏检率与误报率 |
| 让使用者快速定位并修复 | 可筛选的 HTML 报告，定位到行与字段，提供处理建议 | 外部用户是否读得懂、修复是否更快 |
| 支持实验复现 | JSON 保存输入哈希、有效图片清单哈希、版本及检查配置 | 训练环境、模型、优化器和实验全过程追踪 |
| 辅助避免评测污染 | 检查完全相同的样本／输入／图片；可按来源分组检查 | 语义近重复、重新压缩图片、错误分组带来的漏检 |
| 接入训练前的数据门禁 | CLI 退出码可以控制是否启动训练，报告可保存为 CI 产物 | 真实失败训练次数、排查时间、GPU 小时的变化 |
| 保持运行成本低 | 已记录 CPU 上的耗时和峰值 RSS | 大量独立高分辨率图片、冷缓存、远程存储及大规模告警场景 |

这里的 128 个故障样例是基于已知规则设计的回归语料，不能宣传为“真实业务准确率 100%”。
实际数字、环境和计算口径见[基准说明](benchmarks.md)。

## 对论文有什么帮助

**现在就能提供的是实验基础设施与证据。**

- 在方法和附录中记录数据版本、检查规则、集合拆分策略和审计报告，使“做过数据检查”可核验。
- 使用 `--group-key document_id` 或来源／拓扑编号，检验按组划分的 train/eval 是否仍有交叉。
  选择怎样的组才能回答研究问题，仍由研究设计决定。
- 做数据质量消融时，固定测试集、模型版本、训练预算和种子，保留每次数据修订前后的检查报告。
- 通过仓库版本与 [CITATION.cff](../CITATION.cff) 引用实际使用的软件。本项目没有 DOI 或论文接收记录。

[Lee 等人在 ACL 2022 的研究](https://aclanthology.org/2022.acl-long.577/)讨论了语言模型训练数据去重和
训练／测试重叠的影响。它支持认真处理这类问题的研究动机，但其效果数字不能拿来作为本工具的效果；
这里的精确哈希检查也不是那篇论文完整的近重复方法。

如果要围绕本项目形成论文，可以研究：**哪些图文数据缺陷会引发训练失败或扭曲评测，
低成本预检能以怎样的覆盖率、误报率和开销发现它们？** 至少还要补齐：

1. 多来源、许可清晰、独立标注的数据，规则开发集与保留测试集分离。
2. 与基本 schema 校验、上游训练器检查、适当的 Data-Juicer 操作等基线公平对照。
3. 完整问题标注下的规则级 precision/recall、标注一致性、误报分析和性能测量。
4. 固定模型和训练预算，多随机种子的下游实验、置信区间、失败样例及负面结果。
5. 分析修复／删除样本是否改变标签分布、任务难度，而不是只看平均分上升。

目前的合成基准与上游 6 条示例检查不足以支撑上述论文结论。论文价值要靠新问题、可信实验和
可复现贡献建立，不由 README 的设计或 Star 数决定。

## 对业界落地有什么帮助

最直接的位置是“标注／导出完成之后，GPU 任务启动之前”：

1. 标注团队交付 JSONL 与图片后，本地运行预检，生成行级修复清单。
2. 训练平台把退出码接入 CI 或任务提交入口；失败时保留报告，修复并重跑后再启动训练。
3. 数据验收使用同一个格式 profile 和集合拆分政策，减少双方对数据契约的歧义。
4. 评测时把审计报告与实验配置一同保存，辅助排查数据泄漏导致的异常高分。

[LlamaFactory 接入示例](integrations/llamafactory.md)给出了具体字段映射与训练前门禁。
核心检查器离线运行、不加载模型、不修改数据。报告不包含原始对话、ID 值或图片文件名；
哈希和检查结果仍是数据元信息，分享时要遵守数据所有者的要求。

建议下一步验收目标：至少三位独立数据负责人能完成安装、发现问题、修复、重检和归档；
记录真实误报和每次排查用时。先得到试点基线，再制定训练失败率、排查耗时等改进目标。
当前没有真实用户采纳、节省 GPU 小时或降低费用的测量。

## 不应承诺的效果

通过检查不代表标签准确、图文语义一致、任务可解、没有隐私数据、数据许可满足用途，
也不代表模板／tokenizer 兼容、训练收敛或模型精度提高。仍需要真实训练 smoke test。
v0.2 定位为可试用和可复现的公开预览版本。
